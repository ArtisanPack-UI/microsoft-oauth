# ArtisanPack UI Microsoft OAuth

Shared Microsoft identity platform (Entra / Azure AD) OAuth2 broker for the ArtisanPack UI ecosystem. This package handles authentication, token storage and refresh, and scope management for any ArtisanPack UI package that talks to a Microsoft service (Bing Places, Graph, etc.). It is the Microsoft-side sibling of [`artisanpack-ui/google`](https://github.com/ArtisanPack-UI/google).

## Status

Scaffolding only. No feature code has been implemented yet — the OAuth broker, token manager, scope registry, and connection UI will land in subsequent issues.

## Installation

```bash
composer require artisanpack-ui/microsoft-oauth
```
